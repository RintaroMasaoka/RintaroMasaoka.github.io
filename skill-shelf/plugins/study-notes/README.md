# Study Notes

Use `study-notes:study-note` to draft, revise, or review a scholarly study note for a specified reader and learning goal. The package contains the skill, its explanatory-writing references, and examples for an optional HTML manuscript format.

Ordinary Markdown note work requires no renderer. The HTML specification describes authoring and verification; it is not a website implementation. If a working HTML reader is requested, use a compatible renderer already present in the project or build and verify one as part of that task. Hosting is project-specific and is never triggered merely by using the skill.
