# Entrance exam originals

These 16 PDFs are retained in Git as backup copies. This directory is outside Astro's `public/` and is not included in the GitHub Pages site.

The site links directly to the university PDFs recorded in `official-links.json`. Each official PDF was confirmed byte-for-byte identical to its archived copy on 2026-10-17.

Archive filenames match the university filenames and use the admission year. The manifest's `year` records the original examination year; `official_admission_year` is one year later. Site labels use the admission year. Solution PDF/TeX titles, bookmarks, directories, filenames and site links also use the admission year.

Keep backups outside `public/`. Do not add site links to this archive. A public GitHub repository still allows access to these files through GitHub.
