# SUSY diagram sources

Run `sh note-apps/susy-qm/figure-sources/build.sh` from the repository. LaTeX/TikZ typesets every English word and mathematical label in Computer Modern. `dvisvgm --no-fonts` embeds glyph outlines in the SVG; no external font loads are required. Geometry and label sources live in the four `.tex` files. Production outputs live in `public/notes/SUSYQM/diagrams/`.

## Brief and provenance

- `angular-defect`: successor of the source chapter's `angulardefect.pdf`, redrawn from the three-right-angles relation rather than tracing its artwork. Three blue quadrants represent the face angles at a cube vertex. The orange quadrant is the missing angle. Intended inference: the deficit is one quarter-turn. Place immediately after the opening cube/tetrahedron example. Native aspect approximately 0.9; target 380–460 px wide on desktop, contained in the mobile reading width. This is an intrinsic unfolding, not a perspective view of the cube. Letter inventory: `Three faces at one vertex` (panel title), four `\pi/2` labels (three face angles and the deficit), `angular defect` (missing sector).
- `holonomy`: successor of `Holonomy.pdf`, redrawn as the cut-open neighborhood of a cone point with deficit π/2. All four blue arrows in the developed sector have the same planar direction. The radial red cuts are identified. Rotating the endpoint cut back to the start rotates the final arrow by +π/2, as shown in the right panel. Intended inference: fixed direction in the unfolding produces nontrivial rotation after gluing. The path arrow denotes traversal, and the small right-panel arc denotes the comparison angle. Place before the first inference equating deficit and holonomy. Native aspect approximately 1.6; target 640–720 px wide and ≤450 px tall on desktop, fit mobile width. Label inventory: `Unfolded surface`, `After gluing` (panel titles); `start`, `end` (path endpoints); `initial`, `transported` (vectors at one point); `\pi/2` (rotation angle).
- `paired-spectrum`: new diagram for the two partner Hamiltonians. Equal height encodes equal energy. Arrow A maps left to right; A† maps right to left. The example zero mode on the left illustrates that zero energies need not pair; it does not assert general kernel multiplicities. Place before heat-supertrace cancellation. Native aspect approximately 1.35; target 600–680 px wide on desktop, fit mobile width. Label inventory: `E`, `0` (energy axis); `H_0=A^\dagger A/2`, `H_1=AA^\dagger/2` (columns); `A`, `A^\dagger` (directional maps); `\ker A`, `\ker A^\dagger` (zero-energy subspaces); `Positive energies pair; zero modes need not.` (scope statement).

## Author verification and export repair

The original export used TikZ's default PostScript driver. PDF previews had complete diagrams, but the delivered SVGs lost the geometry and had a one-line viewport. Those PDF/PNG checks did not verify the delivered SVG and have been superseded.

Each assigned TeX source now selects `pgfsys-dvisvgm.def` before loading TikZ. The generation script compiles through latex/DVI and dvisvgm, embeds TeX glyph outlines, adds a six-point viewport margin, and asserts nontrivial width/height, direct geometric paths, and glyph uses. The same source-to-SVG path now covers the Morse diagram as well.

The final SVG files themselves were rasterized with macOS Quick Look (`qlmanage -t -s 1400`) into `/tmp/susy-svg-verified/*.svg.png` on 2026-10-21 and all three rasterizations were visually inspected. The filled angle sectors, full cut-open cone path, four parallel arrows, glued-vector comparison, both spectrum columns, and directional partner maps are present, with English TeX lettering. No text elements or external font resources are required by the exports. Quick Look previews are temporary QA files, not deliverables. The build's dimensions and geometry/glyph counts are printed during regeneration.

Final embedded desktop/mobile sizing, dark-theme presentation, independent visual-inference review, and visible-element acceptance remain with the integration/review coordinator. Each source uses `figure-theme.tex` semantic colors. The generator exports both `<name>.svg` and `<name>-dark.svg` from the same geometry and labels. The composition adapter selects the visible variant with the explicit reader theme; the image background follows the page surface, and print uses the light variant. No inversion filter is applied. Standalone SVG inspection does not certify those gates.

Regenerate a bounded subset by passing names, for example `sh note-apps/susy-qm/figure-sources/build.sh paired-spectrum`. The default regenerates all four figures in both themes. `FigureForeground`, `FigureMuted`, `FigureBlue`, `FigureOrange`, `FigureRed`, `FigureBlueFill`, `FigureOrangeFill`, and `FigurePaper` are semantic xcolor names shared by every source. Dark rendering changes contrast while retaining blue/orange/red identity.

For narrow screens, holonomy additionally exports `holonomy-mobile.svg` and `holonomy-mobile-dark.svg` using `FigureStacked`; the geometry is repositioned into a vertical reading sequence with the same labels and relations. Theme production checks are recorded separately in `reviews/susy-qm/theme-update-production.json` and `theme-update-verification.json`; these bind final SVG hashes and include 1440/375 px theme captures.
