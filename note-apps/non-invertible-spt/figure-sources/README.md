# Editable figures

The note embeds fourteen PNG figures from `public/diagrams/`. Their lettering is English and mathematics rendered from TeX with KaTeX; the PNGs include the actual rendered glyphs. Geometry, TeX label inventories, reproducible browser exporters and recorded font evidence are retained here.

| Bundle | Figures |
| --- | --- |
| `early/` | Edge phase cancellation, spacetime defect orientations, fusion bases, tensor-coherence routes, vacuum and defect-sector dimensions |
| `late/` | D symmetry sectors, two CZ layers, string endpoint cancellation, interface charge pairs, SymTFT interval, stacking terms |
| `gauge-connection/` | Local gauge transformations and the preserved connection between states |
| `point-defect/` | Composition of two spatially local defects on a one-dimensional chain |
| `junction-comparison/` | Comparing left and right attachments and transporting them across a phase interface |

Each bundle's README describes its dependencies and local output paths. Regeneration does not edit the manuscript or replace the published figures automatically. After changing a figure, inspect it inside the note at desktop and narrow widths, check its mathematical interpretation and TeX glyph evidence, then adopt the new PNG deliberately.
