# Non-invertible SPT note

This is the editable publication snapshot of the Study note. The working manuscript is maintained in the Study workspace under Non-invertible-SPT/content; update this snapshot and its public build together.

Use Node.js 22.13 or later. Run npm ci, then VITE_SITE_BASE_PATH=/notes/non-invertible-spt npm run build. Copy the generated dist directory to ../../public/notes/non-invertible-spt. The Astro site serves that prebuilt directory on GitHub Pages. Both chapter routes are prerendered, and KaTeX fonts ship in the same build.

Public URL: https://rintaromasaoka.github.io/notes/non-invertible-spt/
