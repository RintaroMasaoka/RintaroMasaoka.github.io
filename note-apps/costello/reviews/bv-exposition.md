## 読者と保持する仕様

- 入力パケットが許可する既知事項：微積分、Taylor展開、二次形式。既読の実際の第1–4章によるGaussian平均、縮約、局所的発散、カウンター項、有限部分の選択。
- 今回構築する理解：ゲージ方向で変わらない式を微分で検査する意味、反場から運動方程式を出す意味、積分の恒等式とQMEの役割、平均とBV演算の順序を比較する操作、解のスケール移送と解を一つ作る問題の違い。
- 原文の符号規約：全作用の指数は正号、奇変数は左微分、BV縮約は `Delta=-partial_J`。第3章の空間ラプラシアンおよび正のスカラー二次形式との区別を保持。
- 既存の条件：境界項消失、有限次元模型の範囲、コンパクト・境界なしの多様体、ラプラス型作用素、適合するBVペアリング、形式級数、古典相互作用の三次以上、正のスケール、定理の原典設定を保持。

## 主な説明単位と型

### BV模型：P01 手段の行き詰まり

仕事：平行移動の重複を検査する微分に、運動方程式を同時に記録する。

| slot | 対象固有の材料・根拠 | 実現位置 |
|---|---|---|
| goal | ゲージ変換で変わらない式と運動方程式の両方を扱う。模型の `S_0(x)` に基づく | 章導入、模型導入 |
| known | `S_0` が `y` に依存せず、通常の微分で依存を調べられる | 模型の最初の二段落 |
| attempt | `sy=c, sc=sx=0` としてゲージ方向の微分を作る | ゴースト・次数の定義後 |
| obstacle | この微分には `S_0'(x)=0` が入らない | 反場節の直前 |
| requirement | 運動方程式を微分の出力にする | 反場節の冒頭 |
| tool | 対になる反場、BV二階微分、BV括弧 | 反場節から「一つの作用」節 |
| retry | 同じ模型で `sy=c` と `sx*=S_0'` を計算 | 拡張作用直後の既存計算と追加の対応説明 |
| gain | 微分で変わらない式を選び、微分から出る式を同一視できる | コホモロジーの定義、二組の計算、運動方程式に比例する式の計算 |

各slotは既存模型の式から確かめた。補助変数は実際にゲージ体積を積分した結果として導入していない。回収は、最初に指定した `sy=c` に運動方程式の出力が加わり、同じ微分で二つの仕事を行えること。一般の特異な方程式と通常の解集合の関数の同一視を許すものではない。

### 熱核とQMEの移送：P02 整合性から決める

仕事：相互作用を平均するとき、QMEの縮約もどう変えるべきかを決める。

| slot | 対象固有の材料・根拠 | 実現位置 |
|---|---|---|
| candidate | 既読の指数演算子による平均、移す相互作用 | 章冒頭、第2章の式の再提示 |
| constraint | 平均前後で対応するQMEを満たす必要 | 章冒頭の具体的な問い |
| test | 二つの操作の順序を交換して差を計算 | `G` の積分、核への書換え、縮約交換節 |
| mismatch | `Q` 単独と平均は交換せず、二つのBV縮約の差が残る | contraction-commutatorと指数交換計算 |
| repair | 各スケールの `hbar Delta_L` を加える | 指数交換節の相殺 |
| recheck | BV演算の移送式の左右が一致 | bv-intertwining、左右の操作の説明 |
| consequence | 最初のスケールでゼロなら平均後もゼロ | QMEを移す節の三行の代入 |
| scope | 入力の解の存在は仮定。初期量子化は残る | 章末の入力条件と未解決の構成問題 |

核の差の式と移送は原論文§10.2、補題10.2.1–10.2.2で確認。自由データの条件は§4.3と§1.1。第6章末で、最後の行をゼロにするためにスケール `L_1` の解が必要だと明記した。

### 最初の量子補正：P02 整合性から決める

仕事：有限な族の存在だけでは決まらない量子補正を、QMEで制約する。

| slot | 対象固有の材料・根拠 | 実現位置 |
|---|---|---|
| candidate | 古典相互作用に未定の量子補正を加えた形式級数 | 章導入と次数の節 |
| constraint | QMEを満たすこと | 量子補正節の冒頭 |
| test | 級数を代入して `hbar` 一次を取り出す | 既存の一次方程式 |
| mismatch | 古典方程式を満たしても `Delta I_0` が残りうる | 一次方程式とその仕事の説明 |
| repair | `d_{I_0} I_1` を指定された右辺に一致させる | 微分の定義直後 |
| recheck | 閉じた右辺であることを確認し、完全であれば消せる | 既存のDelta適用計算、閉と完全の区別 |
| consequence | 類がゼロなら補正を選べ、非零ならこの次数に障害 | コホモロジーによる判定と二解の差 |
| scope | 条件付き判定。具体的理論の障害を消したとはしない。場では繰り込み済みの局所的な破れへ適用 | 場への移行と章末 |

修正可能性は条件付きであり、特定理論の `I_1` を解いたという主張ではない。局所性の定理Bによる有限性と、QMEを満たす量子化を別々に扱う区別は原論文§1.11にも明示されている。局所的な破れは§12の命題12.0.1と補題12.0.2から採用する結果として明記した。
